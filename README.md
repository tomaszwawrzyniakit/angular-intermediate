# OpsBoard

Training application for **Angular Developer (Intermediate): Modern Angular** (Angular 22,
signals, Signal Forms, httpResource, @defer, SSR + hydration, Angular Aria, Bootstrap 5.3).

```bash
npm install
npm start      # http://localhost:4200 (dev server with SSR and the /api/tickets mock API)
npm test
npm run build && npm run serve:ssr:opsboard
```
